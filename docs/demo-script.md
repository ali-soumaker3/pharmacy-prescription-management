# Сценарий 7-минутной защиты: Аптека ИИ

**Строгий лимит:** 7 минут (4:30 презентация + живое демо, 2:30 Q&A).

---

## Поминутный тайминг

### 0:00 – 0:45 | Проблема и решение
- **Проблема:** в аптеках фармацевты вручную разбирают рецепты (включая фото/почерк), ищут остатки, подбирают аналоги и рискуют пропустить аллергию или взаимодействие.
- **Решение:** веб-портал «Аптека ИИ» + автоматизация в университетском `n8n` + мультимодальный `OpenRouter` + `Supabase` + `Telegram` для фармацевта.

### 0:45 – 1:30 | Архитектура и защита от галлюцинаций
- Показать 1 схему: `Web UI (Vercel) → API Proxy (без CORS) → n8n (ai2.mnu.kz) → OpenRouter (строгий JSON) → Supabase → Telegram (Human-in-the-Loop)`.
- Подчеркнуть **3 барьера безопасности**:
  1. ИИ сверяет наличие и цены **только** по реальной базе аптеки (`Supabase`), сервер перепроверяет `id` и цену.
  2. Любой ответ LLM валидируется через `Zod`.
  3. Рецептурные (`Rx`) и конфликтные заказы **никогда** не отпускаются автоматически — требуется подтверждение фармацевта.

### 1:30 – 4:00 | Живое демо (2.5 минуты)
1. **Вкладка «Проверка рецепта»:** нажать **«Вставить пример»** (Амоксициллин 500 мг + Нурофен Форте 400 мг + Омепразол 20 мг + аллергия «Пенициллин») → нажать **«Проверить рецепт»**.
2. **Показать 3 вещи в ответе ИИ:**
   - Красное предупреждение `high`: конфликт амоксициллина с аллергией на пенициллин;
   - Нурофен Форте отсутствует на складе → ИИ автоматически предложил реальный аналог со склада **«Ибупрофен 400 мг (980 ₸)»**;
   - Статус заказа: **«Ожидает подтверждения фармацевта»**.
3. **Human-in-the-Loop в реальном времени:**
   - Показать уведомление, пришедшее фармацевту в **Telegram**, и нажать кнопку **«✅ Одобрить»** (или **«❌ Отклонить»** из-за аллергии).
   - Переключиться на вкладку **«Панель фармацевта»** и **«Склад аптеки»** — статус обновился автоматически (без перезагрузки), а при одобрении остаток уменьшился на 1.

### 4:00 – 4:30 | Тестирование и итоги
- Показать результаты прогона 6 тест-кейсов из `docs/spec.md` (`TC-1` – `TC-6`): точность извлечения JSON, среднее время ответа (2–4 сек), резервный OpenRouter-фолбэк.

### 4:30 – 7:00 | Q&A (частые вопросы комиссии)
- **«Что если LLM сгаллюцинирует цену или несуществующее лекарство?»**  
  → Серверная валидация сверяет каждый `matched_medication_id` с реальным каталогом `Supabase` и пересчитывает сумму на сервере.
- **«Можно ли доверять ИИ в медицине?»**  
  → Система — это ассистент, а не врач: для всех `Rx` и `high`-рисков встроен обязательный Human-in-the-Loop (подтверждение живого фармацевта) + дисклеймер.
- **«Почему Next.js API Routes вместо прямого вызова n8n с фронта?»**  
  → Убирает проблемы CORS с внешним вебхуком `ai2.mnu.kz`, прячет ключи и даёт резервный фолбэк на случай сбоя n8n во время демо.
